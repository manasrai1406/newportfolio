# newportfolio

Personal portfolio of Manas Rai: Data Analyst and Solution Consultant.

Built with Next.js. The home screen features a CSS 3D keyboard, and the sections below animate on scroll.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

All personal content (experience, skills, projects, achievements, links) lives in `src/data/site.ts`.
